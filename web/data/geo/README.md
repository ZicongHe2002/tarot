# GeoNames city data

This directory includes `cities1000.zip` and `admin1CodesASCII.txt` from
[GeoNames](https://www.geonames.org/), downloaded from the
[GeoNames export](https://download.geonames.org/export/dump/).

The data is licensed under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).
GeoNames is credited as the source of city names, coordinates, administrative
regions, populations, and IANA time zones.
